# Project source-of-truth rules

- Only work inside this active repository.
- Treat the current Git working tree as the source of truth.
- Do not inspect, extract, restore, or modify archived ZIP files.
- Do not use files inside archive, backup, old, previous, temp, temporary, or uncertain-review folders as implementation sources.
- Never replace current files with an older ZIP version.
- Before editing, check the current branch, Git status, and latest commit.
- Do not modify files outside this repository unless explicitly instructed.
